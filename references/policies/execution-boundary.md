# Governance / Execution Boundary

Superpowers owns engineering methods such as brainstorming, planning, TDD,
debugging, worktrees, subagents, implementation, and ordinary code review.
HLH reviews the authorization, scope, evidence, findings, handoff, completion,
commit-only, security, and production-readiness aspects of those results.

HLH must remain usable when Superpowers is absent. Superpowers must not infer or
override HLH governance decisions.
